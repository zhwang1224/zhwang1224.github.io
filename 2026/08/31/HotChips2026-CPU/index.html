Hot Chips 2026 Intel CPU 技术总结：Wildcat Lake 与 Diamond Rapids

发表于 2026-08-31 分类于 计算机体系结构 ， 芯粒与先进封装 阅读时长 ≈ 14 分钟
整理 Intel 在 Hot Chips 2026 公布的 Core Series 3（Wildcat Lake）与下一代 Xeon（Diamond Rapids）：前者聚焦主流客户端的计算、I/O、封装与 UCIe，后者介绍 Fan-out Fabric、CBB、Fabric Hub、内存、I/O、先进封装与 APX。

本文整理 Intel 在 Hot Chips 2026 介绍的两款 CPU：面向主流客户端与边缘设备的 Intel Core Series 3（代号 Wildcat Lake），以及面向数据中心的下一代 Intel Xeon（代号 Diamond Rapids）。文章按照两场演讲的内容分别总结产品目标、SoC 构造、互连、内存、I/O、功耗管理、安全与 RAS，并在最后给出简要归纳。

Hot Chips 2026 Intel CPU 技术总结：Wildcat Lake 与 Diamond Rapids

一、Intel Core Series 3（Wildcat Lake）

1.1 产品定位与设计目标

Intel Core Series 3 源自 Core Ultra Series 3（代号 Panther Lake），目标是将较新的客户端 IP 和平台能力扩展到更广泛的主流价位。产品保留 Thunderbolt 4、Wi-Fi 7、Bluetooth 6、安全与 SoC 功能，并覆盖轻薄笔记本以及机器人、智能建筑、销售点终端和智能计量等边缘设备。

演讲给出的平台 AI 算力最高为 40 TOPS，该数字是 CPU、GPU 和 NPU 的合计。相对 Intel Core 7 150U，材料还列出最高 2.7× AI 性能、2.1× 创作与生产力性能，以及最高 64% 的处理器功耗降低。这些结果依赖具体工作负载、配置、电池容量和 OEM 设计，Intel 将详细测试条件列在其 Performance Index 中，因此这些倍数不能脱离原测试环境使用。

Wildcat Lake 的设计路线可以概括为：

  • 维持与 Core Ultra Series 3 相同的制程节点和裸片划分；
  • 通过缩减计算与 I/O IP 的规模降低裸片成本；
  • 从 Foveros 转向有机 MCP，降低封装成本；
  • 调整主板、内存和供电设计，进一步降低平台 BOM；
  • 复用已有验证与研发成果，把主要新增工作集中在客户端 UCIe。

1.2 计算规模调整

Core Series 3 对 Core Ultra Series 3 “U”的计算配置进行了如下调整：

模块 Core Ultra Series 3 “U” Core Series 3
GPU 4 Xe、40 TOPS、支持光线追踪 集成式 2 Xe、20 TOPS
NPU 3 个 Tile、53 TOPS 1 个 Tile、17 TOPS
P-core 与 L3 4 个 P-core、12 MB L3 2 个 P-core、6 MB L3
内存 最高 96 GB、128-bit、8 MB Cache 最高 64 GB、64-bit、4 MB Cache
摄像头 保留 移除
媒体 8K60、VVC 解码与完整特效 4K60、HDR 特效
显示 4×UHBR20 3×HBR3（4K60）

上述调整使计算裸片面积减少 38%。

图 1：Core Series 3 相对 Core Ultra Series 3 “U”缩减 GPU、NPU、P-core、内存、媒体与显示配置。

1.3 I/O 与平台调整

I/O 裸片也按照主流平台需求进行缩减：

模块 Core Ultra Series 3 Core Series 3
Thunderbolt/USB4 3 个带 eDP 复用的接口，共 4 个物理接口 2 个
PCIe 4 条 Gen5、8 条 Gen4 6 条 Gen4
USB 2×USB 3.2、8×USB 2 2×USB 3.2、8×USB 2
摄像头 PHY CSI 移除
音频 4 组扬声器与麦克风、5 个 DSP、4.6 MB 2 组扬声器与麦克风、3 个 DSP、3.0 MB

I/O 裸片面积由此减少 15%。USB 配置保持不变，全局设计也只做少量修改，以减少新增验证问题。

封装方面，Core Ultra Series 3 使用尺寸为 50×25×1.5 mm 的 Foveros 封装；Core Series 3 改用 35×25×1.23 mm 的有机 MCP。Foveros 通过无源 Base Die 连接多个裸片，Core Series 3 移除 Base Die，以降低组装成本和相关良率损失。更少的 I/O 也使封装尺寸可以进一步缩小。

图 2：Core Series 3 采用尺寸更小的有机 MCP，并相应调整平台供电和主板布局。

相对 Intel Core 7 150U，平台级调整还包括：

  • DRAM 总线由 128-bit 调整为 64-bit；
  • Type-3 PCB 由 8 层调整为 6 层；
  • 减少 DRAM 占板面积或 SODIMM 连接器；
  • 增加 LP E-core 电源轨，以支持电池续航；
  • 集成 Wi-Fi 7，并可进一步集成位于 USB Retimer 中的供电控制器。

1.4 客户端 UCIe

从 Foveros 转向有机 MCP 后，原有裸片间连接方式需要调整。Intel 选择 UCIe 连接 Core Series 3 的裸片。材料指出，这套 UCIe 实现的面积比 Core Ultra Series 3 的裸片间连接大 70%，但其目的是获得 MCP 带来的整体成本节省。

UCIe 面积与带宽

移除 Base Die 后，凸点间距从 Foveros 的 36 μm 增加到 UCIe 的 110 μm。面向 PCIe 4 SSD 的数据路径采用 16R16W、8 GT/s 配置，目标带宽为 12 GB/s；显示路径按 4K60 配置为 16W、8 GT/s。更大的凸点间距和数据包化控制带来了更大的 I/O 与控制器面积。

图 3：Wildcat Lake 根据 PCIe 4 SSD 与 4K60 显示需求配置 UCIe 带宽。

协议变化

UCIe 使数据与控制信号的时序发生变化，部分原本独立的边带信号改为数据包传输，并产生额外延迟。该链路同时参与启动、调试、熔丝、安全、显示协议和故障恢复，因此 UCIe Bring-up 成为验证工作的重点。

功耗管理

数据包化与持续运行的时钟会增加链路功耗。Core Series 3 引入多个链路状态，在控制延迟影响的同时降低空闲功耗，材料给出的链路空闲功耗改善最高为 8×。由于空闲系统仍可能有显示流量跨越 UCIe，设计还使用显示流量 QoS 调度，使链路在显示工作期间能够进入更低功耗状态。

信号完整性

链路最初考虑过板上 LDO 和复用现有 VCCAON 电源轨两种 I/O 供电方式。验证结果表明不需要额外 LDO。UCIe 物理链路最高运行在 8 GT/s，不提供 Retry 或 Forward Error Correction；系统监测误码率，并支持降低频率的回退方案。

1.5 裸片良率恢复与产品配置

Core Series 3 对 CPU、GPU 和 NPU 进行频率分档，并允许通过不同核心与加速器配置恢复部分裸片。演讲列出三种配置：

配置 P-core LP E-core GPU NPU
Configuration 1 2 4 2 Xe 有
Configuration 2 1 4 1 Xe 有
Embedded 2 4 1 Xe 无

任一 P-core、任一 Xe Core 和 NPU 都可以参与配置恢复，可恢复部分占计算裸片面积的 29%。LP E-core、显示管线和 I/O 不参与裁剪，材料给出的原因分别是维持电池续航和平台一致性。

图 4：Core Series 3 通过频率分档和 P-core、GPU、NPU 配置形成不同 SKU。

1.6 Wildcat Lake 小结

Wildcat Lake 的主要内容是面向主流客户端重新确定 SoC 与平台规模。计算裸片减少 GPU、NPU、P-core、内存和媒体配置，I/O 裸片减少高速接口与摄像头 PHY；封装从 Foveros 改为有机 MCP，并同步调整内存总线、PCB 和供电。UCIe 是这一 MCP 方案中的关键新增技术，演讲重点介绍了其面积、协议、功耗和信号完整性取舍。最后，CPU、GPU 与 NPU 的分档和裁剪用于形成不同产品配置，并恢复部分计算裸片。

二、Diamond Rapids：下一代 Intel Xeon

2.1 数据中心负载与架构演进

Diamond Rapids 是 Intel 下一代采用性能核心的 Xeon CPU。演讲首先将数据中心 CPU 的要求分为五个方面：

维度 目标
Performance 提高每线程性能，并进行系统级优化
Efficiency 提高每瓦性能
Acceleration 支持 AI、密码学、压缩和网络等加速
Scalability 提供模块化架构、一致性与 Scale-up 能力
Security 支持内存加密、隔离、信任根和 RAS

Intel 将 Xeon 的互连和集成方式概括为从 Ring、Mesh、Tiled Mesh、Modular Mesh 发展到 3D Mesh；物理集成则从单片设计扩展到 2.5D 分解和 2.5D/3D 组合。Diamond Rapids 的设计重点是处理器在大规模系统中移动、处理和保护数据的能力。

2.2 Fan-out Fabric Architecture

Diamond Rapids 采用 Fan-out Fabric Architecture，整体由以下部分组成：

  • 可扩展的 Compute Building Block（CBB）；
  • 集中承载内存、I/O 和固定功能加速器的 Fabric Hub；
  • 连接计算与内存的 Unified Memory Fabric；
  • 提供外部连接的 Flexible I/O Fabric。

图 5：四个 Compute Building Block 与两个 Fabric Hub 通过内存和 I/O Fabric 连接。

2.3 Compute Building Block

每个 Core Chiplet 最多包含 16 个核心及其 L2 Cache。核心通过 3DXbar 连接到 Base Tile 上的 LLC，LLC 由整个 CBB 共享。Base Tile 还包含 Caching Agent、Snoop Filter 和 Die-to-Die 接口。

该结构支持在一个 Base Tile 上扩展 Core Chiplet 数量，也支持在一颗处理器中扩展 CBB 数量。

图 6：Core Chiplet 通过 3DXbar 访问 Base Tile 上由 CBB 共享的 LLC。

2.4 Fabric Hub 与内存子系统

Fabric Hub 同时连接 FlexBus I/O Fabric 和 Unified Memory Fabric。其内部包括灵活 I/O 子系统、内存子系统、I/O Cache、加速器、Snoop Filter、Home Agent 和内存加密等模块。Diamond Rapids 的内存子系统带宽最高为 1.6 TB/s。

图 7：Fabric Hub 集成内存控制、I/O、缓存、一致性过滤、加密和固定功能加速器。

内存子系统的主要模块包括：

  • Memory Controller（MC）：调度 DDR 访问，提供 ECC、电源管理和 Rowhammer 防护；
  • Memory Value Function（MVF）：支持 CXL 内存的 1LM、Flat2LM 和镜像；
  • Memory Encryption Engine（MSE）：支持 DDR 或 CXL 内存加密；
  • Home Agent 与 Home Snoop Filter：通过片上 Snoop Filter 维护一致性。

2.5 Flexible I/O 与固定功能加速器

每个 Fabric Hub 提供 4 组 x16 高速 I/O，并另外提供 4 条 PCIe Gen4 Lane 用于平台基础设施。每组 x16 可以配置为 PCIe Gen6、CXL 3、UPI 3 端口或它们的组合。

每个 Fabric Hub 还提供最高 16 MB I/O Cache，并包含片上 Snoop Filter 和 Caching Agent。每个 Hub 内有两个 Accelerator Complex，集成 Intel QAT、DSA 和 IAA。

在整颗 SoC 上，两个 Fabric Hub 合计提供：

  • 128 条高速 I/O Lane；
  • 8 条 PCIe Gen4 Lane；
  • 最高 2 TB/s 聚合双向 I/O 带宽。

由于高速 Lane 可以配置为 PCIe、CXL 或 UPI，2 TB/s 表示聚合 I/O Fabric 带宽，并不对应单一接口类型。

2.6 功耗与热管理

Diamond Rapids 将功耗管理划分为四类独立 DVFS Domain：

  • Core DVFS Domain；
  • CBB Uncore DVFS Domain；
  • I/O DVFS Domain；
  • Memory DVFS Domain。

处理器还支持保留 L2 Cache 的新核心空闲状态、Priority Core Turbo、Fabric Hub 功耗与热管理、基于 MR4 的内存热管理，以及 UXI 和 PCIe 的 L0p。系统可根据使用场景在计算、I/O 和内存之间分配功耗预算。

2.7 SoC 规格与物理构造

Diamond Rapids 的公开规格如下：

类别 规格
Compute 4 个 CBB；最高 256 核；所有 CBB 合计最高 1.28 GB LLC
Memory 16 通道；最高 DDR5-8000；最高 MRDIMM-12800；最高 1.6 TB/s
I/O 128 条高速 Lane；PCIe Gen6、CXL 3.0、UPI 3；另有 8 条 PCIe Gen4 Lane
Security Intel TDX、TDX Connect、SGX
Acceleration Intel AMX、AVX 10.2、QAT、DSA、IAA

物理构造包括：

  • 2 个采用 Intel 3 工艺的 Fabric Hub Tile；
  • 16 个采用 Intel 18A-P 工艺的 Core Chiplet；
  • 4 个采用 Intel 3-T 工艺的 Base Tile；
  • Core Chiplet 与 Base Tile 之间使用 Foveros 3D Direct Hybrid Bonding Interface；
  • 基板上的裸片间连接使用 UCIe-S 铜链路。

图 8：Diamond Rapids 由 Core Chiplet、Base Tile 和 Fabric Hub Tile 组成，并结合 3D 混合键合与基板互连。

2.8 Intel 18A-P

演讲列出 Intel 18A-P 相对 18A 的以下变化：

  • 功耗降低 18%；
  • 性能提高 9%；
  • 热阻降低 20%—40%；
  • Via 电阻降低 10%—30%；
  • 提供 PowerBoost 双触点低电阻选项；
  • 在 ULVT 与 LVT 之间新增第 5 种 Logic Vt；
  • Skew Corner 收紧 33%；
  • 改善制程变化。

这些百分比基于业界标准核心子模块，并不是 Diamond Rapids 整颗处理器的实测收益。

2.9 Intel APX

Diamond Rapids 支持 Intel Advanced Performance Extensions（APX）。APX 的主要内容包括：

  • 新增 16 个通用寄存器，使整数 GPR 总数达到 32；
  • 为 r16—r31 提供新编码，并通过 XSAVE 保存新增状态；
  • 提供三操作数 NDD 指令；
  • 支持 Flag Suppression；
  • 增加 64-bit Absolute Branch、Conditional ISA 和 Spill/Fill 优化指令；
  • 保持旧 x86 代码兼容；
  • 既有源代码可以通过重新编译使用 APX 能力。

演讲没有给出 APX 的独立性能数据，只说明重新编译的软件可以利用新增寄存器和指令获得性能提升。

2.10 安全与 RAS

在既有产品中，一致性目录状态存放在 DRAM 中。Diamond Rapids 将目录状态移动到片上 Snoop Filter，并以片上 Snoop Filter Directory 取代 DRAM-resident Directory State。

材料列出的效果包括：

  • 减少 Cache Lookup 延迟；
  • 减少一致性流量；
  • 简化内存子系统；
  • 不再使用 DRAM 空间保存目录状态；
  • 保留完整 ECC 保护并提高可靠性。

安全功能还包括 Intel TDX、TDX Connect、SGX 和内存加密。内存控制器提供 ECC 与 Rowhammer 防护，CXL 内存也可以使用加密与镜像能力。

2.11 面向 Agentic AI 基础设施的配置

Intel 将 Diamond Rapids 定位为面向下一代 Agentic AI 基础设施的 CPU，列出的相关能力包括：

  • 最高 256 个性能核心；
  • 1.28 GB Last Level Cache；
  • AMX 与 AVX 10.2；
  • 支持 FP8、FP16 和 BF16；
  • 16 通道 DDR5/MRDIMM，内存带宽最高 1.6 TB/s；
  • 128 条高速 I/O Lane，聚合双向带宽最高 2 TB/s。

演讲没有给出 Diamond Rapids 的核心频率、TDP、上市时间或端到端应用性能，因此上述内容应理解为公开的架构与规格信息，而不是完整的性能评估。

2.12 Diamond Rapids 小结

Diamond Rapids 的核心内容是 Fan-out Fabric Architecture。四个 CBB 负责扩展核心与 LLC，两个 Fabric Hub 集中提供内存、I/O、加速器、一致性过滤和内存安全功能。完整 SoC 最高包含 256 个核心、1.28 GB LLC、16 通道 DDR5/MRDIMM 和 128 条高速 I/O Lane。物理实现采用 18A-P Core Chiplet、Intel 3-T Base Tile、Intel 3 Fabric Hub Tile、Foveros 3D Direct 和 UCIe-S。演讲还介绍了独立 DVFS Domain、APX、片上目录、TDX/SGX 以及 AMX/AVX 10.2 等功能。

三、两场演讲的总体总结

Wildcat Lake 与 Diamond Rapids 面向不同产品范围，因此两场演讲的重点也不同。

Wildcat Lake 主要说明 Core Series 3 如何从 Core Ultra Series 3 派生：缩减计算和 I/O 配置，改用有机 MCP，调整主板与内存接口，并为客户端 MCP 引入 UCIe。其公开数据集中在裸片面积、封装尺寸、平台配置、UCIe 实现和良率恢复。

Diamond Rapids 主要介绍下一代 Xeon 的模块化架构：以 CBB 组织 Core Chiplet 与共享 LLC，以 Fabric Hub 集中内存、I/O、固定功能加速器和一致性功能，并通过 3D 混合键合与 UCIe-S 形成完整 SoC。其公开数据主要是最大核心数、缓存、内存、I/O、裸片构造和功能支持，尚未包含完整产品性能与功耗信息。

两份材料共同表明，Intel 的 CPU 设计已经同时覆盖核心、缓存、裸片间互连、封装、内存、I/O、功耗管理、安全和产品配置。Wildcat Lake 的重点是主流客户端的规模与成本控制，Diamond Rapids 的重点是高端服务器的模块化扩展。
