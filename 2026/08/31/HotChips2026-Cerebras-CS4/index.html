Hot Chips 2026 Cerebras CS-4：晶圆级引擎的机架级架构

发表于 2026-08-31 分类于 计算机体系结构 ， 晶圆级系统 阅读时长 ≈ 10 分钟
忠实整理 Cerebras 在 Hot Chips 2026 公布的 CS-4 与 NEXUS 机架级平台：WSE-3 Turbo 片上内存和 Fabric、模块化 Backpack、垂直供电、水冷、晶圆 I/O、集群互连及推理性能口径。

Cerebras CS-4 是一套以 WSE-3 Turbo 晶圆级引擎为计算核心的机架级系统。单台 CS-4 集成 3 颗 WSE-3 Turbo，公开规格包括 750 PFLOPS AI 计算、132 GByte 内存、129.6 PByte/s 内存带宽、160.5 PByte/s Fabric 带宽和 7.2 Tbit/s I/O 带宽。演讲的重点不仅是晶圆级芯片，还包括 NEXUS 模块化机架、Backpack、供电、水冷、晶圆 I/O 和多晶圆集群。

Hot Chips 2026 Cerebras CS-4：晶圆级引擎的机架级架构

一、CS-4 与 WSE-3 Turbo

1.1 产品定位

Cerebras 将 CS-4 定位为面向大模型推理的晶圆级系统。相对 CS-3，CS-4 在一个机架中安装 3 个晶圆级 Backpack，每个 Backpack 包含一颗 WSE-3 Turbo。总体包括：

  • 提高 Token 输出速度；
  • 提高每瓦吞吐量；
  • 增加单机架计算、内存和 I/O 资源；
  • 使用模块化机架设计支持部署和后续升级；
  • 支持多晶圆集群与分解式推理。

相对 CS-3，CS-4 的 Token 速度最高提升 2×，每瓦吞吐量最高提升 10×。Output Speed(Tokens/sec)相较于传统 GPU 系统快 30x。

1.2 片上内存带宽

Cerebras 将 WSE-3 Turbo 与 GPU 的主要差异概括为模型权重所在的位置。GPU 将大模型权重放在片外 HBM 中，计算单元通过外部存储接口访问权重；WSE-3 Turbo 将 LLM 权重放在晶圆的片上内存中，使存储靠近计算核心。

演讲给出的带宽对比如下：

系统 内存带宽
NVIDIA Rubin 22 TByte/s
Cerebras CS-4 WSE-3T 43,200 TByte/s

WSE-3T 的内存带宽标为 Rubin 的 2,000×。

图 1：WSE-3T 的 43,200 TByte/s 片上内存带宽与 Rubin 的 22 TByte/s 对比。

1.3 Mixture-of-Experts 模型映射

对于 Mixture-of-Experts（MoE）模型，Cerebras 对比了 GPU 集群和 WSE-3T 的部署方式。

在 GPU 系统中，专家可能分布到多个 GPU，需要使用张量并行和专家并行聚合内存带宽，同时产生 GPU 间通信。Cerebras 给出的 WSE-3T 方案则是：

  • 所有专家运行在一颗晶圆级芯片上；
  • 专家交错放置在晶圆内存中；
  • 不需要跨芯片通信；
  • 不需要复杂的跨设备路由。

图 2：Cerebras 将 MoE 专家交错放置在单颗 WSE-3T 的晶圆内存中。

1.4 晶圆内 Fabric

WSE-3T 的晶圆内 Fabric 带宽为 53.5 PB/s，互连全部位于晶圆上，不需要机内线缆。作为对比，演讲列出 Rubin NVL72 的 NVLink 带宽为 260 TB/s，并提到系统包含约 5,000 根线缆。Cerebras 将 WSE-3T 的片上 Fabric 带宽标为 GPU 互连的 200×。

图 3：WSE-3T 在片上提供 53.5 PB/s 晶圆 Fabric，演讲强调其不依赖线缆。

这里比较的是晶圆片上 Fabric 与机架内 GPU 互连，两者处于不同物理层级。该数字主要说明 Cerebras 将大量通信保留在晶圆内部的设计方式。

二、NEXUS 模块化机架平台

2.1 机架总体结构

CS-4 使用 NEXUS Rack-Scale Platform。计算和水路位于机架后部，电源位于前部。后部安装可插拔 Backpack，每个 Backpack 包含一颗晶圆级引擎；单台 CS-4 共安装 3 个晶圆级 Backpack。

NEXUS 平台的模块化目标包括：

  • 简化构建；
  • 缩短部署时间；
  • 允许电源、计算和 I/O 独立演进；
  • 允许更换或升级 Backpack；
  • 支持后续 CS-5 和 CS-6 产品。

图 4：NEXUS 将前部供电与后部可插拔晶圆级 Backpack 分开布置。

2.2 CS-4 Backpack

CS-4 Backpack 包含晶圆封装、晶圆 I/O 模块、供电与冷却结构。相对 CS-3，演讲列出以下变化：

模块 CS-4 Backpack 的变化
Wafer I/O Module 带宽提高 2×；延迟速度提高 2×；支持模块化升级
Wafer Package 直接垂直供电；供电能力提高 2×；冷却能力提高 2×
Manufacturing 组件减少 50%；自动化程度提高 60%

图 5：Backpack 集成晶圆封装、晶圆 I/O 模块、垂直供电与冷却结构。

材料中的 2×、50% 和 60% 均以 CS-3 为比较基线。

三、供电与冷却系统

3.1 垂直供电

以 GPU 供电为对照：功率转换器与硅负载之间的距离约为 50 mm，电流需要穿过 PCB；为了降低电阻损耗，PCB 需要增加铜层。

CS-4 使用 54.5 V DC 母排，不在晶圆和功率转换器之间使用传统 PCB 供电路径。DC/DC 功率转换器均匀分布并直接放置在晶圆背面，转换器到硅负载的距离约为 0.5 mm。这一距离相对 GPU 的变化标为 100× 改善，可以降低额外电阻损耗与寄生电感。

图 6：DC/DC 功率转换器直接位于晶圆背面，供电距离约为 0.5 mm。

3.2 前部电源模块

机架前部安装 AC/DC Power Supply Module：

  • 输入电压最高为 277 VAC；
  • 输出电压为 54.5 VDC；
  • 每个 Backpack 最多配置 30 个电源模块；
  • 电源冗余可以配置为 5+1、4+1、3+1 或 4+2；
  • 每个电源模块由 30 A 断路器保护；
  • 机架顶部最多接入 6 路 AC 输入；
  • 机架两侧布置完全相位平衡的 AC 供电互连；
  • 风冷风扇负责冷却 Backpack 内的小型器件。

3.3 后部水冷

计算和水路集中在机架后部。集成水冷系统包括：

  • 位于两侧的供水与回水歧管；
  • 带阀门的干式快速断开接头；
  • 用于保证流量的调节执行器；
  • 监测泄漏与冷凝的检测模块；
  • 监测水流速率以及进水、出水温度的仪表；
  • 出现异常时关闭所有 Power Supply Module AC 电源的联动功能。

水路与前部高压 AC 电源区相互隔离，光纤线缆则通过集成导管进行保护。Backpack 可以从后部拆卸和更换。

四、晶圆 I/O 与 CS-4 系统规格

4.1 新一代晶圆 I/O

CS-4 使用新的晶圆 I/O 模块，将 Fabric 从晶圆边缘扩展到外部网络。该模块包含：

  • 新型 Direct Wafer Link 接口；
  • 支持标准 RoCE 协议网络；
  • 更高带宽和更低延迟；
  • 可编程、可替换的模块化设计。

图 7：晶圆 I/O 模块从晶圆边缘引出 Fabric，并连接 Direct Wafer Link 与 RoCE 网络。

4.2 CS-3 与 CS-4 规格对比

CS-4 通过 3 个 WSE-3 Turbo Backpack 扩展单机架资源。给出的规格如下：

指标 CS-3 CS-4
AI Compute 125 PFLOPS 750 PFLOPS
晶圆 1×WSE-3 3×WSE-3 Turbo
内存容量 44 GByte 132 GByte
内存带宽 21.6 PByte/s 129.6 PByte/s
Fabric 带宽 26.7 PByte/s 160.5 PByte/s
I/O 带宽 1.2 Tbit/s 7.2 Tbit/s
I/O 延迟 5 μs 2 μs

图 8：CS-4 在一个机架中集成 3 个 WSE-3 Turbo，并增加计算、内存、Fabric 和 I/O 资源。

五、从单颗晶圆扩展到 CS-4 集群

5.1 晶圆间互连

CS-4 Cluster 通过新的高速晶圆链路和低延迟数据包流水线连接多个晶圆。演讲给出的改进包括：

  • 每颗晶圆带宽提高 2×；
  • 网络延迟速度提高 1.7×；
  • 晶圆到晶圆速度提高 2.5×；
  • 网络内部延迟为 3 μs；
  • 晶圆到晶圆延迟为 2 μs；
  • 到用户和分解式设备的网络延迟为 3 μs。

图 9：CS-4 Cluster 通过 Direct Wafer Link 和低延迟数据包流水线连接晶圆、用户与分解式设备。

5.2 大模型流水线

演讲以 CS-3 Cluster 说明大型前沿模型的跨晶圆执行方式：

  1. 将大部分高通信量保留在晶圆内部，使用晶圆内高带宽 Fabric；
  2. 晶圆之间主要传输激活值，降低跨晶圆带宽需求；
  3. 将大型模型流水线划分到多个晶圆上。

材料称，更高的 I/O 带宽可以缩短晶圆间跳转，对于 10T 参数模型，跨晶圆部分的延迟低于 0.2 ms。

5.3 分解式推理

CS-4 被设计为支持 Disaggregated Inference。其 I/O 接口可以连接用户网络以及 GPU/ASIC 等分解式设备。演讲没有进一步给出分解式系统中的任务划分协议或完整性能数据，公开内容主要集中在 Direct Wafer Link、RoCE、带宽和延迟。

六、推理性能与数据口径

6.1 演讲给出的性能结论

Cerebras 展示了 CS-3 在多种模型上的生产推理输出速度，模型范围包括 Gemma、Llama 3.3 70B、GPT OSS-120B、GLM 4.7-355B、Kimi K2.7 1T 和 GPT 系列。随后给出的 CS-4 总结包括：

  • 相对 GPU 的输出速度最高提高 30×；
  • 相对 CS-3 的 Token 速度最高提高 2×；
  • 相对 CS-3 的每瓦吞吐量最高提高 10×；
  • Token Capacity 最高提高 10×；
  • 组件数量减少 50%。

6.2 发布时间口径

演讲称 CS-4 已提供 Early Access，并计划在 2026 年第三季度后期 General Availability。NEXUS 平台同时面向后续 CS-5 和 CS-6 设计。

七、总结

Cerebras CS-4 将 3 颗 WSE-3 Turbo 集成到一个 NEXUS 机架中。每颗晶圆提供片上内存和高带宽 Fabric，机架通过可插拔 Backpack 组织计算、晶圆 I/O、垂直供电和水冷。系统前部集中 AC/DC 供电，后部放置计算与水路，并通过模块化晶圆 I/O 接入 Direct Wafer Link 和 RoCE 网络。

CS-4 的机架级设计围绕三个方面展开：第一，将模型权重和高通信量尽量保留在晶圆内部；第二，通过模块化 Backpack、供电和水冷结构扩展到三晶圆机架；第三，通过新型晶圆 I/O 和低延迟链路构建多晶圆集群及分解式推理系统。
