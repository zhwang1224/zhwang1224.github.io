Hot100 算法题思路汇总-回溯

  1. 全排列

给定一个不含重复数字的数组 nums，返回其所有可能的全排列。

核心思路：path 保存当前已经选择的排列，used[i] 表示下标 i 对应的数字是否已被当前路径使用。每一层递归都遍历所有数字，从尚未使用的数字中选择一个加入路径。

当路径长度等于数组长度时，说明已经形成一个完整排列，将当前路径加入结果。递归返回前，需要依次撤销路径末尾元素和使用标记，使同层循环能够尝试其他选择。

排列问题中的元素顺序有意义，因此下一层仍然从数组开头遍历，并通过 used 防止同一个元素在一条路径中被重复选择。

时间复杂度：O(n · n!)，其中复制每个排列需要 O(n)；除返回结果外，空间复杂度为 O(n)。

  1. 子集

给定一个元素互不相同的整数数组 nums，返回该数组所有可能的子集。

核心思路：子集问题的每个搜索节点都代表一个合法答案，因此进入递归函数后，先将当前 path 加入结果，而不必等到路径达到固定长度。空路径对应空集。

参数 start 表示当前层可以从哪个下标开始选择。选择 nums[i] 后，下一层从 i + 1 开始，只向后选择元素。这样既能防止同一个元素被重复使用，也能避免以不同顺序生成相同子集，因此不需要额外的 used 数组。

时间复杂度：O(n · 2^n)，其中共有 2^n 个子集，复制路径最多需要 O(n)；除返回结果外，空间复杂度为 O(n)。

  1. 电话号码的字母组合

给定一个仅包含数字 2 到 9 的字符串，按照电话按键上的数字与字母映射，返回它能表示的所有字母组合。

核心思路：递归参数 idx 表示当前需要处理的数字位置。根据 digits[idx] 找到对应的字母集合，依次选择其中一个字母加入 path，然后递归处理下一个数字。

当 idx 等于数字字符串长度时，说明每个数字都已经选择了一个对应字母，将当前字符串加入结果。回溯时删除最后加入的字符，以尝试当前数字对应的其他字母。

空字符串没有可生成的组合，需要直接返回空结果，不能把空路径作为一个有效组合加入答案。

设输入长度为 L，每个数字最多对应 4 个字母。时间复杂度上界为 O(L · 4^L)，其中包含复制结果字符串的开销；除返回结果外，空间复杂度为 O(L)。

  1. 组合总和

给定一个无重复元素的整数数组 candidates 和一个目标整数 target，返回所有和为目标值的不同组合。数组中的同一个数字可以被无限次选择。

核心思路：currentSum 保存当前路径中所有数字的和，start 限定当前层从哪个下标开始选择。当选择 candidates[i] 后，下一层仍然传入 i，表示当前数字可以继续使用；同时不再考虑下标小于 i 的数字，从而避免以不同顺序生成相同组合。

当当前和等于目标值时，记录路径并返回；当当前和大于目标值时，由于候选数字均为正数，继续添加数字不可能重新得到目标值，因此可以直接剪枝。

回溯时必须同时撤销路径中的最后一个数字和 currentSum 中对应的数值，保证两个状态始终一致。

设候选数字数量为 n，最小候选值为 x，最大搜索深度不超过 D = target / x。搜索树的粗略时间复杂度上界为 O(n^D · D)；除返回结果外，空间复杂度为 O(D)。

  1. 括号生成

给定括号对数 n，返回所有能够组成的有效括号组合。

核心思路：open 和 close 分别记录当前路径已经使用的左括号和右括号数量。只要左括号数量小于 n，就可以继续添加左括号；只有当右括号数量小于左括号数量时，才能添加右括号。

第二个条件保证任意前缀中的右括号数量都不会超过左括号数量，因此搜索过程只会生成可能成为合法答案的路径，不需要先枚举全部字符串再逐个判断是否合法。

当路径长度达到 2n 时，n 对左右括号已经全部使用完，并且路径必然合法，可以直接加入结果。

合法结果共有第 n 个卡特兰数 C_n 个。生成并复制每个长度为 2n 的字符串，时间复杂度为 O(n · C_n)；除返回结果外，空间复杂度为 O(n)。

  1. 单词搜索

给定一个字符网格 board 和一个字符串 word，判断该单词能否由网格中上下左右相邻的单元格依次组成。同一个单元格不能在一条路径中重复使用。

核心思路：枚举网格中的每个单元格作为起点，再通过回溯匹配单词中的字符。递归参数 index 表示当前需要匹配的字符位置；如果坐标越界，或者当前格子的字符与 word[index] 不同，当前路径立即失败。

字符匹配成功后，先将当前格子临时改为 '#'，表示它已经被当前路径占用，再向四个方向搜索下一个字符。无论搜索成功与否，返回前都要恢复原字符，使该单元格能够参与其他起点或其他路径的搜索。

当 index 等于单词长度时，说明前面的所有字符均已匹配成功。四个递归调用使用逻辑或连接，找到任意一条合法路径后即可停止继续搜索。

设网格大小为 m × n，单词长度为 L。时间复杂度上界为 O(mn · 4^L)；递归调用栈的空间复杂度为 O(L)。

  1. 分割回文串

给定一个字符串 s，将它分割成若干子串，使每个子串都是回文串，返回所有可能的分割方案。

核心思路：start 表示当前尚未分割部分的起始位置。枚举结束位置 end，得到候选子串 s[start...end]。只有当候选子串是回文串时，才将它加入路径，并从 end + 1 开始继续分割。

当 start 到达字符串末尾时，说明原字符串已经被完整切分，并且路径中的每一段都经过了回文判断，因此可以将当前方案加入结果。

回溯过程枚举的是相邻字符之间“切或不切”的选择。代码在搜索过程中直接判断回文并剪去非法分支，避免生成完整分割方案后再统一检查。

设字符串长度为 n。分割方案的数量为指数级，当前写法每次还需要线性判断回文和构造子串，时间复杂度上界可记为 O(n^2 · 2^n)；除返回结果外，递归调用栈和当前路径占用 O(n) 空间。

  1. N 皇后

在一个 n × n 的棋盘上放置 n 个皇后，使任意两个皇后都不在同一行、同一列或同一条对角线上，返回所有不同的棋盘布局。

核心思路：按行放置皇后，递归参数 row 表示当前正在处理的行。由于每层递归只处理一行，因此天然保证皇后不会位于同一行；只需要额外记录已经占用的列和两类对角线。

对于位置 (row, col)：

  • 同一条主对角线 \ 上的 row - col 相等。加上 n - 1 后，其下标范围为 [0, 2n - 2]。
  • 同一条副对角线 / 上的 row + col 相等，下标范围同样为 [0, 2n - 2]。

如果当前列和两条对角线都没有被占用，就记录皇后位置并继续处理下一行。递归返回后撤销三个占用标记，以尝试当前行的其他列。

当 row == n 时，每一行都已经成功放置一个皇后。此时根据 queens[row] 记录的列位置构造棋盘并加入结果。

搜索复杂度通常记为 O(n!)；若共有 S 个解，构造结果棋盘还需要 O(S · n^2) 时间和输出空间。除返回结果外，递归栈和状态数组的空间复杂度为 O(n)。
